Device password

The password secures web administration only. The AP remains open. Changing the password invalidates every session without restarting the receiver.

Local management

Authenticate from the internal AP or any reachable private IPv4 network, including routed VLANs. No subnet allowlist is required. Do not expose HTTP to the Internet.

Physical recovery

Press and release BOOT five times within ten seconds to erase saved settings and return to first-time setup. RST only restarts the device. No remote factory reset endpoint exists.

Development storage protection

AES-GCM encrypted secret values; PBKDF2 password hash; key stored in flash for reversible development. No eFuse programming or production physical-extraction protection. HTTP has no transport encryption.
